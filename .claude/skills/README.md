# Project skills

Three checklists Claude Code can run on this repo. Invoke with `/name`.

| Skill | Use it for |
|---|---|
| `/test-suite` | create or extend tests; decide between a unit test, an `evals.py` case and a `golden.json` row |
| `/ux-review` | review the web UI, the agent's replies or the terminal, ranked by severity; `--fix` restyles to the house design in `ux-review/design.md` (dark, measured contrast, Google Fonts, plain CSS) |
| `/security-audit` | threat model and checklist for the agent, the local server, secrets and dependencies |

Each `SKILL.md` is written to be read on its own. The checklists are the
content; the report formats at the bottom keep results comparable between
runs and between students.
