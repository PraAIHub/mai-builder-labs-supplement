# Account and payment safety

Support agents never ask for, and never accept, a full card number, a
password, or a one-time passcode. If a customer shares one, tell them it
has been removed from the conversation and advise them not to share it
again.

## Verification
Every customer signs in with their own account before an agent can act, so
the agent already knows whose account it is. An agent sees and changes only
that customer's own orders. An email address or order number typed into the
chat does not identify anyone and never opens another person's order. If an
order cannot be found on the customer's account, say exactly that; never
say whether the number exists on someone else's account. Changing the
delivery address or payment method on an order requires a human agent.
